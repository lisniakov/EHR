# EHR

EHR (Electronic Health Record) is a simple project for storing and managing patient medical information in digital form.

The system demonstrates how patient records can be organized, stored, and accessed in a structured way. This project was created for learning and experimentation with healthcare data management systems.

## Overview

Electronic Health Records are digital versions of patient medical histories.  
They help store important information such as personal data, medical history, diagnoses, and treatments.

This project provides a basic implementation of an EHR system.

## Features

- Create and manage patient records
- Store basic patient information
- View and update medical data
- Simple and easy-to-understand structure
- Easy to extend with new functionality

## Installation

Clone the repository:

```bash
git clone https://github.com/lisniakov/EHR.git
cd EHR
````

Install dependencies if needed.

For Python:

```bash
pip install -r requirements.txt
```

For Node.js:

```bash
npm install
```

## Running the Project

Example commands to run the project:

```bash
python main.py
```

or

```bash
npm start
```
